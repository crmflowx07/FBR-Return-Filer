# FBR Return Filer

Android client ERP for FBR return filing, reminders, documents, payments and reports.

- Package: `com.muzamil.fbrreturnfiler.v13`
- Android: minSdk 26 / targetSdk 35
- Storage: local SQLite
- UI: FBR blue/white premium mobile ERP
- Direct dashboard launch (no blocking Get Started screen)

## Build
```bash
gradle :app:assembleDebug
```

The latest installable APK is stored in `releases/FBR-Return-Filer-v13.apk`.
